# 🗂️ flashcards-python-app

O **Flashy** é um aplicativo de desktop interativo desenvolvido em Python para ajudar no aprendizado de novos idiomas. Ele utiliza cartões de memória (flashcards) que mostram uma palavra e, após 3 segundos, revelam a tradução.

## 🚀 Funcionalidades
- **Temporizador Inteligente:** O cartão vira automaticamente após 3 segundos. O tempo reseta se você pular para a próxima palavra antes do tempo acabar.
- **Persistência de Dados:** Palavras que você marcou como "conhecidas" são removidas da lista e o progresso é salvo em um arquivo CSV externo.
- **Interface Intuitiva:** Desenvolvida com a biblioteca Tkinter para uma experiência limpa e funcional.
- **Portabilidade:** Preparado para ser transformado em executável (.exe) mantendo todas as imagens e dados.

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- **Tkinter** (Interface Gráfica)
- **Pandas** (Manipulação de dados/CSV)
- **PyInstaller** (Para geração do executável)
